 # Thème 33w Été 25 – Club Voyage
 
 ### Auteur  :Nadia Ouafi

## Titre du projet
Thème WordPress “Club Voyage” pour la mise en valeur de destinations touristiques.

## Description
Ce projet consiste à créer un thème WordPress personnalisé pour un site de voyage.  
Le thème met en avant les destinations avec :
- Des cartes dynamiques pour chaque catégorie (hors “Populaire”)  
- Une section accordéon alimentée via la REST API pour accéder aux détails complets des destinations  
- Une galerie d’images par destination  
- Un formulaire d’inscription à la newsletter sur la page d’accueil  
- Un footer amélioré intégrant les icônes sociales et une image sélectionnée depuis le Customizer  
- Un design responsive et structuré selon le standard BEM  
- Gestion des images par défaut lorsque certaines images ne sont pas présentes  

Toutes les fonctionnalités ont été développées avec SCSS, PHP et JS commentés et organisés pour une maintenance facile.
